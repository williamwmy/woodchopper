# Custom Sprites

Place your custom sprite files in this directory to replace the default generated sprites.

## Supported Sprites:

- **player.png** - Player character (32x32)
- **tree.png** - Normal trees (16x40)
- **sturdy_tree.png** - Sturdy trees (18x42)
- **oak_tree.png** - Oak trees (20x45)
- **maple_tree.png** - Maple trees (18x42)
- **birch_tree.png** - Birch trees (16x40)
- **pine_tree.png** - Pine trees (18x45)
- **stump_enemy.png** - Stump enemies (24x16)
- **spirit_enemy.png** - Spirit enemies (24x24)
- **mountain.png** - Mountain boundaries (100x150)
- **base_building.png** - Base building (150x80)
- **base_marker.png** - Base marker (50x50)
- **ground.png** - Ground texture (800x100)

## How to Use:

1. Create PNG files with the exact names above
2. Place them in this directory
3. Restart the game to see your custom sprites

## Notes:

- If a custom sprite is not found, the game will use the default generated sprite
- Make sure your sprites match the recommended dimensions for best results
- PNG format is recommended for transparency support
